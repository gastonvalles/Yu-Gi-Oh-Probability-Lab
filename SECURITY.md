# Seguridad

YGOUltraLab no tiene cuentas ni base de datos, pero el repositorio es público: si encontrás una vulnerabilidad, **no abras un issue público**.

- Avisale a Gastón Valles por [LinkedIn](https://www.linkedin.com/in/gastonvalles/) o [Instagram](https://www.instagram.com/gaston_valles/) con lo que viste y cómo repetirlo.
- Si el repositorio tiene activado el aviso privado de vulnerabilidades de GitHub, también podés usar «Report a vulnerability» en la pestaña Security.
- Se corrige la versión de `main` (la que está en línea). Qué se protege y qué límites se aceptaron: `docs/seguridad.md`.

If you find a vulnerability, please don't open a public issue: contact the author through the links above.
