# Idiomas: español e inglés

La app está completa en español (voseo rioplatense) y en inglés. Este documento dice cómo está armado, cómo se agrega o cambia un texto y cómo se traduce.

## Cómo funciona

- **Qué idioma se ve.** Lo que la persona eligió (se guarda en `localStorage`, clave `ygo-lab:locale`); si nunca eligió, el primer idioma del navegador que la app tenga (español o inglés); si ninguno, inglés. El selector **ES | EN** está abajo del menú lateral (escritorio) y en el cajón de la hamburguesa (celular). Elegir otro idioma lo guarda y **recarga la página**: lo importante está guardado (deck, reglas, builds, combos) y sólo se pierde lo que estaba abierto, como una práctica en curso.
- **Dónde viven los textos.** En `src/i18n/`:
  - `es/<área>.ts` es la fuente: un objeto `clave → texto` por área. `en/<área>.ts` tiene las mismas claves traducidas, con el tipo `Translated<typeof es>`: si falta una clave, sobra una o un plural pasa a ser texto, **no compila**.
  - `index.ts` trae `t()`, `getLocale()`, `setLocale()` y las etiquetas de `Intl` (`numberLocale()`, `dateLocale()`, `currencyLocale()`). `rich.tsx` trae `tRich()` para textos con partes resaltadas.
  - Un área = un archivo = un prefijo de clave: `common`, `shell` (barra, pie, mascotas, calculadora de LP, `components/ui`), `deck` (builder, importar, exportar), `search` (buscador, detalle de carta, precios), `roles` (clasificación), `rules` (motor del Lab: reglas del sistema, validaciones, sugerencias), `lab` (pantalla del Lab), `builder` (armador y editor de reglas), `practice` (práctica y mesa) y `meta` (meta, replays y comparar).
- **Qué no se traduce.** Nombres y textos de las cartas (los da YGOPRODeck en inglés), arquetipos, jugadores y torneos, y todo lo que escribió la persona (nombres de decks, reglas, builds y combos). Tampoco lo que va a la consola ni los datos guardados: lo guardado no lleva texto de la interfaz, se arma al dibujar.
- **Páginas estáticas.** `index.html` queda en español para los buscadores y los links compartidos (en el navegador, `syncSiteMeta()` pasa la descripción al idioma elegido). `privacidad.html` y `privacy.html` son dos páginas, enlazadas entre sí, y `404.html` está en los dos idiomas.

## Agregar o cambiar un texto

1. Agregá la clave en `es/<área>.ts` y su traducción en `en/<área>.ts`. La clave empieza con el prefijo del área y sigue por pantalla o componente: `practice.mat.undo`.
2. En el código, `t('practice.mat.undo')`, o `t('practice.draw', { count: 2 })` si el texto lleva `{parámetros}`. Los parámetros se chequean al compilar: uno de más, uno que falta o una clave que no existe es un error de tipos.
3. Si cambia con la cantidad, el valor es un plural: `{ one: 'Robás {count} carta', other: 'Robás {count} cartas' }`, y `count` elige la forma.
4. Si lleva partes resaltadas, el texto lleva etiquetas y se dibuja con `tRich`: `'Con <b>+</b> agregás una copia.'` y `tRich('search.hint', { b: (text) => <strong>{text}</strong> })`.
5. Corré `npx vitest --run src/__tests__/i18n.test.tsx src/__tests__/i18n-literals.test.ts`. El primero chequea que los dos idiomas tengan las mismas claves, `{parámetros}` y `<etiquetas>`; el segundo, que no haya quedado texto en español escrito en el código (`I18N_SCAN=src/components/search` lo limita a una ruta). Un texto en español que tiene que quedar (alias de búsqueda, nombres viejos para migrar datos) se marca con `// i18n-ignore: motivo` en su línea o en la de arriba.

### Reglas que mantienen esto simple

- **Nunca llames `t()` al evaluar un módulo** (constantes de nivel superior). Las tablas guardan claves (`as const`) y el texto se arma al dibujar, en una función o en el componente: `const TONE_KEY = { ok: 'shell.tone.complete' } as const` y después `t(TONE_KEY[tone])`. Lo mismo vale para `Intl.NumberFormat` y `Intl.DateTimeFormat`: se crean al usarlos, con `numberLocale()` o `dateLocale()`.
- **Un mensaje es una frase entera.** No armes oraciones pegando pedazos: el orden de las palabras cambia de un idioma a otro. Lo que varía (un nombre, un número ya formateado con `formatInteger`) va como parámetro.
- **Fechas, números y listas con el formato del idioma.** Un día con año: `formatDay(fecha)` ("12/10/2026" en español, "Oct 12, 2026" en inglés, donde el número solo se confunde día con mes). Un número entero: `formatInteger`. Una lista con "y": `new Intl.ListFormat(getLocale(), …)`. Nunca `'es-AR'` ni `'es-ES'` sueltos: `numberLocale()`, `dateLocale()` y `currencyLocale()`.
- **El worker del Lab también arma texto** (los avisos de validación): `lab-worker-pool.ts` le pasa el idioma como nombre del worker y `t()` lo lee de ahí. Un test chequea que todo `new Worker(…)` lo haga.
- **Plural con el número formateado.** `count` elige la forma y `t()` lo escribe tal cual; si el número lleva separador de miles, pasá además el formateado con otro nombre: `{ one: '{n} copia', other: '{n} copias' }` y `t('shell.copies', { count: copies, n: formatInteger(copies) })`.
- **Constantes exportadas con texto** que leen otros módulos (`export const X = { title: '…' }`) conservan su forma con getters: `{ get title() { return t('…') } }`. Así el texto se arma al leerlo y nadie más cambia.
- **Los textos no se guardan.** Lo que persiste (reglas, builds, combos) son datos; el texto se arma al mostrarlo.
- **En los tests el idioma es español** (`src/i18n/test-setup.ts`). Para probar el inglés: `applyLocale('en')` y volver con `applyLocale('es')` en `afterEach`.

## Tono y glosario

Español: voseo rioplatense, informal y directo ("armá", "tenés"). Inglés: segunda persona informal ("build your deck"), imperativo en las acciones, frases cortas, sin signos de exclamación que el español no tenga. Mayúscula inicial sólo en la primera palabra de un botón o título (como en español). Los términos del juego, con su nombre oficial en inglés (Normal Summon, Set, Special Summon, Graveyard, Banished…).

| Español | Inglés |
|---|---|
| mano / robar / barajar | hand / draw / shuffle |
| Cementerio / Destierro (desterrar) | Graveyard (GY) / Banished (banish) |
| Zona de Monstruo / Zona Extra / Mágicas y Trampas / Zona de Campo | Monster Zone / Extra Monster Zone / Spell & Trap Zone / Field Zone |
| Invocación Normal / Colocar / Invocación Especial | Normal Summon / Set / Special Summon |
| Invocación por Sacrificio / por Volteo | Tribute Summon / Flip Summon |
| ataque / defensa / boca arriba / boca abajo | Attack / Defense / face-up / face-down |
| Material Xyz / desacoplar | Xyz Material / detach |
| Ficha / contador / Escala | Token / counter / Pendulum Scale |
| Salida / Problema | Opening / Problem |
| regla / reglas base / tus reglas | rule / base rules / your rules |

| yendo 1º / yendo 2º | going first / going second |

Los roles (Starter, Extender, Handtrap, Boardbreaker, Brick, Garnet, Engine, Non-engine, Disruption) ya están en inglés en la app y quedan igual en los dos idiomas.
